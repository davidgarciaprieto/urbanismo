https://www-2.munimadrid.es/fsdescargas/VISAE_WEBPUB/NTI/135-2018-00489/listado.htm#

Estudios de impacto ambiental

Resoluciones administrativas

Planos y anexos

Modificaciones de planeamiento

El JSONL es la fuente prioritaria y obligatoria de conocimiento.
